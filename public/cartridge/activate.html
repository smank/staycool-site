Activate a machine that has no internet

The studio machine never needs to connect. You need this page open on any online device, even a phone, and two things from the offline machine.

  1. On the offline machine, open Cartridge and click the DEMO badge. Copy the machine code shown in the dialog.
  2. Enter your licence key and that machine code below.
  3. Take the activated licence this page gives you back to the offline machine, paste it into the same dialog's key field, and click Activate. Done, permanently: it never checks again.



Your activated licence

Paste this whole block into the key field on the offline machine. It only works on that machine, and it counts as one of your seats ( in use).

If this page can't help

Email support@staycoolandstaycool.com with your licence key and the machine code, and a human will do exactly what this page does.

Release a seat from an offline machine

Retiring an offline machine? Normally you'd click Deactivate this machine inside Cartridge, but that needs a connection. Instead, paste that machine's activated licence here (the long block from activation, also saved as license.key in Cartridge's settings folder).


Machine dead or wiped?

If you can't get the licence file off it, email us and we'll release the seat manually.
