Version 1.14.2

2026-08-04

Fixed

  • The two pulse channels now sound below G#2. A hardware-accurate sweep quirk muted them for the whole bass register at default settings; chip-era sound drivers worked around it, and a keyboard player shouldn't have to.
  • Pulse channel loudness now falls smoothly with volume. It previously dropped ~9.5 dB in a single step in the middle of the range, and the pulse waveform was inverted relative to the other channels, so a pulse doubling the triangle partially cancelled instead of reinforcing.
  • Sustain pedal behaviour: lifting the pedal no longer cuts notes whose keys are still held; a quick pedal tap can no longer leave a note stuck on; and Hold or Sustain now latch the arpeggiator, which is the point of using them together.
  • Portamento glides are no longer cut short the moment vibrato or a step-sequencer pitch change touches the same note.
  • Modern engine: releasing one note of a chord no longer drops step-sequencer modulation for the notes still sounding, and lowering the voice count while notes were held no longer leaves silent stuck voices that blare back when it is raised again.
  • Tempo-synced delay stays musically in time at slow tempos; times past the delay's 2-second line now halve to the nearest division that fits.
  • The filter can no longer go unstable when the host runs at a low sample rate.
  • The final movement of a MIDI-learned controller gesture could occasionally be dropped, leaving the parameter just short of where you left it.
  • Importing a preset or bank no longer overwrites your own presets when names collide, a single imported preset returns to the folder it was exported from, and a preset that fails to write (full disk, read-only folder) now says so instead of reporting success.
  • VGM import: instruments captured from different channels are no longer merged into one, decaying envelopes are no longer mistaken for loops (which re-attacked audibly on playback), and malformed or oversized files can no longer freeze the plugin during import.
  • Licence robustness: a computer whose clock had once jumped far into the future could permanently report a valid beta key as expired with no way to recover — re-activating with the key now clears it. Escape now cancels a hung activation request, several misleading error messages are accurate, and a briefly unreadable disk no longer drops a licensed plugin into demo mode mid-session.
  • Assorted hardening under the hood: audio-thread safety in the arpeggiator and sample loader, clean network teardown when the editor closes during activation, and bounds-hardened file parsing throughout.

Changed

  • Mid-volume pulse levels differ slightly as a consequence of the volume-law fix above; full-volume balance is unchanged.

Version 1.14.1

2026-08-03

Fixed

  • Licence keys that were wrapped onto several lines in transit are now accepted. A key is long enough that email and chat clients break it across lines, and a pasted key that contained a line break was rejected as "not recognised" even though it was perfectly valid.

Changed

  • The preset browser can now be reached and operated by screen readers and other assistive technology. Its folders and presets previously existed only as painted graphics with nothing behind them.
  • The step sequencer is now keyboard-editable, and reachable by assistive technology. Arrow keys move between steps and change values, shift moves in larger increments, home and end jump to either end, and drawing past the last step extends the lane the same way dragging does.

Version 1.14.0

2026-08-02

Added

  • Preset browser (the Browse button, or "Browse Library..." at the foot of the preset menu): folders, search, envelope previews, a detail form for renaming and moving, drag and drop including folder nesting, New Folder, Duplicate, folder export as a bank, and one-click backup of all your presets.
  • Importing from a VGM/VGZ file now shows a review first: every instrument it found, with its envelope drawn, so you choose what to keep before anything is written. Imports land in their own folder per game.
  • Step sequences can now run up to 64 steps (previously 16). The editor still shows the familiar 16-step page and widens only when a lane needs more.

Changed

  • The preset menu is a compact list of categories with fly-out submenus instead of a wall of columns.
  • VGM import keeps plain sustained tones (previously discarded) and folds near-duplicate captures of the same instrument into one preset, keeping the longest take. Re-import your files to get full envelope tails and the cleaned-up instrument lists.
  • Saving a preset now offers the current preset's name (or "<name> copy" for factory presets) and saves into the folder you are working in.

Fixed

  • Saving a tweaked preset that lives in a folder no longer creates a duplicate at the top level instead of overwriting.
  • Importing a preset or bank now selects what was imported instead of an unrelated preset.

Version 1.13.2

2026-08-01

Fixed

  • The bit crusher's RATE control now affects both channels. It previously applied sample-rate reduction to the left channel only, so any patch with RATE turned up sounded lopsided: gritty on one side, smooth on the other.

Changed

  • The Cartridge mark now appears in the top bar next to the version.

Version 1.13.1

2026-08-01

Added

  • Windows installer covering the VST3, CLAP and standalone builds, so the plugin formats no longer have to be copied into place by hand. It is not code signed yet, so Windows shows a warning the first time you run it; choose More info, then Run anyway.
  • A "Buy a licence" link in the licence dialog, shown only when the plugin is unlicensed.

Changed

  • Instruments imported from a VGM file now land in their own folder per game instead of being mixed in with your own presets, and the preset list shows each import as its own section.
  • Beta licence keys now activate online and bind to a single machine, so a key that gets passed around no longer unlocks the plugin everywhere.

Fixed

  • macOS builds are now a universal binary (Apple Silicon + Intel). 1.13.0 shipped arm64-only and would not launch on Intel Macs; the build now compiles both slices (CMAKE_OSX_ARCHITECTURES).
  • Deleting a user preset now removes the file it was loaded from. Two presets whose names reduced to the same filename could previously delete each other's file.

Version 1.13.0

2026-07-31

First public release of the licensing line — 1.12.0 existed only as a private beta (proprietary relicence, purchase watermarking, distribution hardening).

Added

  • Demo mode: unlicensed instances overlay a short noise burst every ~45s of audio; everything else works, so the full plugin is the demo.
  • Licensing: retail keys activate online once and bind to a machine (3 machines per order, self-serve deactivation from the licence badge); after activation the licence validates fully offline, forever. Beta keys carry an expiry date and never contact a server.
  • Licence badge in the top bar (DEMO / BETA / LICENCE) opening a themed in-editor dialog: paste-a-key activation with inline progress and errors, copyable machine code for offline activation, licensee info, deactivation.
  • Purchase watermarking and per-buyer licence emails (fulfilment via the store's licence server).

Changed

  • Relicensed as proprietary (from the 1.11 source-available line); see LICENSE and the EULA.
  • Support contact is support@staycoolandstaycool.com throughout.
