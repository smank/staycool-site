Version 1.13.0

2026-07-31

First public release of the licensing line — 1.12.0 existed only as a private beta (proprietary relicence, purchase watermarking, distribution hardening).

Added

  • Demo mode: unlicensed instances overlay a short noise burst every ~45s of audio; everything else works, so the full plugin is the demo.
  • Licensing: retail keys activate online once and bind to a machine (3 machines per order, self-serve deactivation from the licence badge); after activation the licence validates fully offline, forever. Beta keys carry an expiry date and never contact a server.
  • Licence badge in the top bar (DEMO / BETA / LICENCE) opening a themed in-editor dialog: paste-a-key activation with inline progress and errors, copyable machine code for offline activation, licensee info, deactivation.
  • Purchase watermarking and per-buyer licence emails (fulfilment via the store's licence server).

Changed

  • Relicensed as proprietary (from the 1.11 source-available line); see LICENSE and the EULA.
  • Support contact is support@staycoolandstaycool.com throughout.

Version 1.11.0

2026-07-05

Added

  • Step sequencer is now a first-class SEQ tab (FX | MOD | SEQ) with its own transport header; presets with embedded sequences auto-open it.
  • Edited-preset indicator next to the preset name.
  • 95 factory presets (79 Classic + 16 Modern), including a sampled DPCM rock kit, step-sequenced riffs, and a Modern Init blank canvas.
  • Tag-driven release workflow (v* tags build, test, package all platforms and open a draft GitHub release).
  • Overwrite confirmation when saving over an existing user preset.

Changed

  • UI scale is a true zoom (fonts and bars scale together).
  • Status bar removed; Hold and version moved to the top bar, octave/velocity readout onto the keyboard.
  • Cmd+S saves a preset; Solo/Mute are Cmd+Shift+S / Cmd+Shift+M.
  • Pan values display as C / L50 / R50; DPCM rate defaults to 15.
  • A/B toggle no longer interrupts audio unless the engine changes.

Fixed

  • Toggle parameters restore exactly under strict hosts (pluginval clean).
  • Step-sequence edits can no longer tear against the audio thread (seqlock).
  • User preset save/export now captures the full patch: VRC6 routing gates, per-channel pans, step-sequencer enable/rate/sync, tempo-sync params, and embedded step-sequence data. Preset/bank import no longer strips embedded sequences.
  • LFO vibrato and the step-sequencer pitch lane now work in the Modern engine.
  • No allocation or first-use synthesis on the audio thread in the DPCM drum path (fixes a likely audio glitch on the first drum hit of a session).
  • MIDI CC and MIDI Learn parameter changes are applied from the message thread instead of the audio thread.
  • Step counts from corrupt session data are clamped (out-of-bounds read guard).
  • Host BPM of zero no longer produces infinite tempo-synced rates.
  • Output limiter sanitises non-finite samples.
  • Reese Detune preset actually detunes; Sub Bass differentiated from Rock Bass; Chiptune Poly Lead fleshed out.
  • Pan gains computed per block (~16 fewer transcendental calls per sample).
