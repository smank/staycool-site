Licence & activation

Most licence questions are one of these five. Yours not among them? Skip to getting in touch and we'll sort it out.

My licence key hasn't arrived

Keys are emailed within a minute or two of purchase, from licences@staycoolandstaycool.com. Check your spam folder first, since it's an address you've never received from before. Still nothing? Recover your key here with your order number and email — it works any time, even years later. Or email us and we'll resend it.

"This licence is already active on 3 machines"

Each licence covers three machines at once. To free one up, open Cartridge on a computer you no longer need it on, click the LICENCE badge, and choose Deactivate this machine. The seat is released immediately and you can activate elsewhere.

If that machine is dead, sold, or wiped, you can't deactivate from it. Email us and we'll release the seat manually.

"This key is bound to a different machine"

You're pasting a key that has already been activated and tied to another computer. Use your original purchase key instead, and Cartridge will activate this machine as a new seat.

The machine has no internet

Use the offline activation page from any online device, even a phone. Click the DEMO badge on the offline machine, copy the machine code from the dialog, enter it on that page with your licence key, and paste the licence it gives you back into the dialog. The studio machine never connects.

Prefer email, or is the page not working? Send us the machine code and your key and a human does the same exchange. Either way, after activation Cartridge never needs the internet again on any machine.

Can I get a refund?

Yes. If Cartridge isn't right for you, email us within 14 days of purchase and we'll refund it. No form to fill in, no justification needed.

If something is broken rather than just not for you, tell us what went wrong first. We'd rather fix it, and you'd rather have the plugin working.

My beta key stopped working

Beta keys carry an expiry date and stop unlocking the plugin when they pass it. That's expected, not a fault. Still testing for us? Email and we'll issue a fresh one.

The plugin itself

I hear a burst of noise every so often

That's demo mode. Unlicensed instances overlay a short noise burst roughly every 45 seconds; everything else works normally. Click the DEMO badge and enter your licence key and it stops immediately.

My DAW doesn't list Cartridge

Restart the DAW so it rescans plugins. Logic and GarageBand in particular often need a full quit and relaunch rather than just closing the project.

If it's still missing, check the format is installed: Logic and GarageBand need the Audio Unit, while Live, Cubase, Studio One and Reaper generally use VST3. The setup guide lists where each format belongs.

Windows warns when I run the standalone

The Windows build isn't code signed yet, so SmartScreen shows "Windows protected your PC" the first time. Choose More info then Run anyway. The VST3 and CLAP plugins load in your DAW with no warning at all. The macOS build is signed and notarised by Apple, so it never shows this.

Where are my presets stored?

On macOS, ~/Library/Cartridge/Presets. On Windows, %APPDATA%\Cartridge\Presets. Each preset is a single file, so you can back them up or move them between machines by copying that folder. Uninstalling leaves them alone unless you ask it not to.
