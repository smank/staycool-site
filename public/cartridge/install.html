CARTRIDGE SETUP GUIDE
Install Activate Seats Manual

Install

macOS and Windows both have installers. Linux is a zip you copy into place. Either way, restart your DAW afterwards so it rescans plugins. When in doubt, install VST3 and the standalone app.

macOS

  1. Open the downloaded Cartridge DMG, then open the installer inside it.
  2. Tick the formats you want. Standalone, AU, VST3, and CLAP are all selected by default; unused ones do no harm.
  3. Enter your password when macOS asks, and you're done.
Signed & notarised

The installer is signed and notarised by Apple, so it opens without security warnings. To remove Cartridge later, run Applications › Stay Cool and Stay Cool › Uninstall Cartridge. It keeps your presets and licence unless you tell it otherwise.

Windows

  1. Run the downloaded Cartridge installer (.exe).
  2. SmartScreen may say “Windows protected your PC” because the build isn't signed yet. Click More info › Run anyway.
  3. Tick the formats you want (VST3, CLAP, and the standalone app) and finish. The installer puts each in the right folder for you.
Unsigned

The Windows build isn't code-signed yet, so SmartScreen warns once on the first run. It's safe to continue. Remove Cartridge later from Settings › Apps; that leaves your presets and licence in place.

Linux

Plugin folders

  • Cartridge.vst3~/.vst3
  • Cartridge.clap~/.clap
  • Cartridgeanywhere on your path
Logic & GarageBand

Quit the DAW fully and relaunch to trigger a rescan. Closing the project is not enough.

Activate

Your licence key arrives by email right after purchase, from licences@staycoolandstaycool.com. Check spam if it hasn't landed within a few minutes.

  1. Open Cartridge in any format and click the DEMO badge in the top bar.
  2. Paste your licence key and click Activate.
  3. Done. Activation needs the internet once. After that the licence verifies offline, forever.

One licence covers up to three machines. Activate each one the same way, with the same key.

No internet on that machine?

The licence dialog shows a machine code with a copy button. Send us that code along with your key and we'll return a licence bound to that machine, which activates with no connection at all.

Moving machines

Retiring a computer, or hit the three-machine limit? Click the LICENCE badge on the machine you're leaving behind and choose Deactivate this machine. The seat frees up immediately and you can activate elsewhere.

If that machine is gone for good and can't deactivate itself, email support with your order number and we'll release the seat for you.
